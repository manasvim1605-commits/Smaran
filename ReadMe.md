# SMARAN

**Every Mind Has a Story to Continue.**

SMARAN is a memory-support application designed to engage users through interactive activities and games.

## Project Modules

- Player Authentication
- Caregiver Authentication
- Memory Games
- Game Performance Tracking
- Progress Monitoring
- Reminders

## Technologies Used

- HTML
- CSS
- JavaScript (Handles interactions and sends requests)
- Flask (Processes requests and application logic)
- REST API+JSON (Transfers data between frontend and backend)
- MySQL (Stores and retrieves information)

## Development

This project is being developed as part of the MCA curriculum.
