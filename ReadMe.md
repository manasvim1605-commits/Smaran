# SMARAN

**Every Mind Has a Story to Continue.**

SMARAN is a memory-support application designed to engage users through interactive activities and games.

## Project Modules

- Player Authentication
- Caregiver Authentication
- Memory Games
- Game Performance Tracking
- Progress Monitoring
- Reminders

## Technologies Used

- HTML
- Flask
- CSS
- JavaScript
- JSON

## Development

This project is being developed as part of the MCA curriculum.
